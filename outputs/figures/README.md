# Figures

This folder holds the **figures** generated by `code/run_all.py`.

## Expected contents

- `figure1_wage_distribution.png` — distribution of starting wages by state and
  wave (reproduces the paper's Figure 1).
- `figure_extension_randomization.png` — permutation null distributions for the
  randomization-inference extension.
- `figure_extension_heterogeneity.png` — subgroup DiD forest plot for the
  heterogeneity extension.

Figures are regenerated on every run and are not committed.
