# Tables

This folder holds the **tables** generated by `code/run_all.py`.

## Expected contents

- `table1_survey_response.csv` — survey response, waves 1 and 2 (Table 1).
- `table2_means.csv` — means of key variables by state and wave (Table 2).
- `table3_employment.csv` — average employment before/after and the DiD (Table 3).
- `table4_reduced_form.csv` — reduced-form models for the change in employment
  (Table 4).
- `table5_specification_tests.csv` — alternative employment measures (Table 5).
- `table6_nonwage_outcomes.csv` — non-wage outcomes (Table 6).
- `table7_prices.csv` — reduced-form models for the change in meal price
  (Table 7).
- `extension_randomization.csv` — randomization-inference p-values.
- `extension_heterogeneity.csv` — heterogeneous treatment effects.

Tables are regenerated on every run and are not committed.
