# Tables

This folder holds the **tables** generated by `code/run_all.py`.

## Expected contents

- `table3_employment_did.csv` — average employment before/after and the
  difference-in-differences estimate (reproduces the paper's Table 3).
- `table4_reduced_form.csv` — reduced-form models for the change in
  employment (reproduces the paper's Table 4).
- Additional tables from the independent extension, if any.

Tables are regenerated on every run and are not committed.
